همین چیزی که دارید می‌خوانید: یک جلد مانگا که نسخهٔ فارسی‌اش چاپ اصلی است، راوی‌ای به نام سیمو، و عکسی که یک اسکریپت کوچک جوهرش زده.

- **Astro** همهٔ صفحات را به HTML ایستا تبدیل می‌کند؛ صفحهٔ اصلی تقریباً هیچ جاوااسکریپتی ندارد.
- تصویرسازی‌ها SVG دست‌نویس‌اند، اسکرین‌تون CSS است و بافت کاغذ هنگام build ساخته می‌شود.
- **چایخانه** برای رادیوی لوفای و تایمر پومودورو کنار گذاشته شده؛ داخل یک React island که با ورق‌زدن صفحه‌ها قطع نمی‌شود.
