The previous edition of this site: a portfolio drawn as Volume 1 of a Persian-fable manga, with a Simorgh narrator and a cover photo inked by a build script. It lives on its own git branch.

This workstation edition keeps the same foundation:

- **Astro** renders every page to static HTML. The home page ships no framework runtime.
- The effects (decrypted text, the dot grid, the live terminal) are small TypeScript files, not a UI library.
- The **~/lab** workspace is reserved for a lofi radio and a pomodoro timer. They'll live in a React island that keeps playing while you move between pages.
