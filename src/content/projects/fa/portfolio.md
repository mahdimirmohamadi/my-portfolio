نسخهٔ قبلی همین سایت: پورتفولیویی به شکل جلد اول یک مانگای حماسی فارسی، با راوی‌ای سیمرغی و عکسی که یک اسکریپت build جوهرش زده بود. آن نسخه روی برنچ git خودش زنده است.

این نسخهٔ «ورک‌استیشن» همان پایه را نگه می‌دارد:

- **Astro** همهٔ صفحات را به HTML ایستا تبدیل می‌کند؛ صفحهٔ اصلی هیچ runtime فریم‌ورکی ندارد.
- افکت‌ها (متن رمزگشایی‌شونده، شبکهٔ نقطه‌ای، ترمینال زنده) فایل‌های کوچک TypeScript‌اند، نه یک کتابخانهٔ UI.
- فضای کاری **~/lab** برای رادیوی لوفای و تایمر پومودورو کنار گذاشته شده؛ داخل یک React island که با جابه‌جایی بین صفحه‌ها قطع نمی‌شود.
